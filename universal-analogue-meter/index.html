Universal analogue meter

any data→a needle on a dial

Version one of my universal analogue meter, with an e-ink display that can be set to any scale. Here, for example, renewable electricity on the GB grid, and the moon phase.

Parts: a Raspberry Pi Zero, a Waveshare display, and Meccano gears.
